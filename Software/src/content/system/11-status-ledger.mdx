Every number quoted anywhere on this site appears here once, with how it was arrived at. If a figure
is not in this table it is not a claim.

- **MEASURED** — obtained from the hardware or from a held-out evaluation, and reproducible
- **SIMULATED** — obtained from a model or a generated test set, not from the device
- **TARGET** — a design goal or a placeholder, not yet verified
- **PLANNED** — not built, not measured, listed so the gap is visible
