<Why>
  The enclosure is airtight because the device is meant to be worn where dust,
  rain and solvent spray are normal. Sealing the case also isolates it
  acoustically, so the reference microphone is not listening to the board's own
  mechanical noise through the shell.
</Why>

<Why>
  The reference microphone is deliberately outside, away from the speaker's
  mouth. The further its voice-to-noise ratio is from the primary microphone's,
  the cleaner the noise estimate the adaptive filter gets — and the less speech
  the filter can cancel by mistake.
</Why>

### Firmware

<StatusTag status="IN DEMO" /> The firmware is written in C for the ARM core: a
fixed 10 ms frame loop, DMA-fed microphone buffers and a static memory plan with
no allocation after start-up. It runs the demo build end to end today; hardening
is scheduled rather than done.
